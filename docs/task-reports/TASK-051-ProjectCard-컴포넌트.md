# TASK-051. ProjectCard 컴포넌트

## 상태
완료

## 날짜

## 작업 요약
대시보드에서 프로젝트 하나를 카드 형태로 보여주는 `ProjectCard` 컴포넌트를 만들었습니다. 이 컴포넌트는 순전히 화면에 보여주는 역할만 하고, 클릭했을 때 어디로 이동할지는 직접 정하지 않습니다. 대신 `onClick` prop으로 넘어온 함수에 현재 프로젝트 객체를 그대로 전달하기만 합니다. 실제 페이지 이동(라우팅)은 이 컴포넌트를 사용하는 Dashboard 페이지(TASK-054)가 책임집니다. 이렇게 역할을 나누면 ProjectCard를 다른 화면에서도 재사용하기 쉽고, 테스트하기도 더 쉬워집니다.

카드에는 제목(heading), 설명, 마지막 활동 시각이 표시됩니다. 설명이 없는(null) 프로젝트는 "설명이 없습니다"라는 안내 문구가 대신 보입니다. 마지막 활동 시각은 날짜 포맷팅 없이 서버에서 온 값을 그대로 "Last activity: ..." 형태로 보여줍니다. 아직 작업(Task) 진행률 집계 기능이 없기 때문에 최소한의 플레이스홀더로 구현했습니다.

## 기술 결정 (해당 시)
- 카드 루트 요소는 `<div role="button" tabIndex={0}>`로 구현했습니다. 실제 `<button>` 태그 대신 이 방식을 택한 이유는 카드 내부에 제목(heading), 설명 등 여러 블록 요소를 자유롭게 배치해야 하기 때문입니다. 키보드 접근성을 위해 `tabIndex={0}`을 주고 `onKeyDown`에서 Enter 키를 감지해 `onClick`을 호출하도록 했습니다.
- `onClick`은 옵션(optional) prop으로 선언했고, 호출 시 `onClick?.(project)` 형태로 안전하게 호출하여 prop이 없을 때도 클릭해도 에러가 나지 않도록 했습니다.
- 설명 표시는 `project.description || '설명이 없습니다'`로 처리하여 null뿐 아니라 빈 문자열(`''`)도 플레이스홀더로 자연스럽게 대체되도록 했습니다.
