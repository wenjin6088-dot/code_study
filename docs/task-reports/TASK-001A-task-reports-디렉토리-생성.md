## 작업 요약
이 프로젝트는 "작업을 하나 끝낼 때마다 무엇을, 왜, 어떻게 했는지를 한국어로 기록한다"는 규칙(헌법 II장, Task Report 의무)을 가지고 있습니다. 이 기록들을 보관할 전용 서랍인 `docs/task-reports/` 디렉토리를 만들었습니다.

비유하자면, 요리를 할 때마다 "오늘 무슨 요리를 했고, 어떤 재료를 썼고, 맛은 어땠는지"를 적어두는 요리 일기장을 꽂아둘 책꽂이를 만든 것입니다. 이 책꽂이가 있어야 앞으로 작성될 `TASK-002-...md`, `TASK-003-...md` 같은 개별 일기장(보고서)들이 한곳에 정리됩니다.

이 디렉토리는 T001에서 만든 `docs/` 디렉토리의 하위 폴더이며, 실제로 이 디렉토리에 저장되는 첫 두 개의 보고서가 바로 이 TASK-001A 보고서와 TASK-001 보고서입니다 (자기 참조적으로, 이 폴더를 만드는 작업 자체도 이 폴더에 기록을 남기는 첫 사례입니다).

## 기술 결정
- 헌법(my_constitution.md) II장에 명시된 경로(`docs/task-reports/`)와 파일명 규칙(`TASK-{NNN}-{short-title}.md`)을 그대로 적용했습니다.
- T001과 별도 Task로 분리한 이유는 tasks.md에서 T001A가 "헌법 I-B 요구사항 충족"이라는 독립적인 목적을 가진 별도 항목으로 정의되어 있기 때문입니다. 디렉토리 생성 자체는 T001에서 함께 처리했지만, 보고 의무 준수를 명확히 추적하기 위해 보고서를 별도로 작성했습니다.

## 비고
- 이후 모든 Task는 이 디렉토리에 `TASK-{NNN}-{제목}.md` 형식으로 보고서를 추가해야 합니다 (헌법 X장, "Task Report 없이 Task 완료 처리" 금지 조항).
- git 저장소가 초기화되면 이 디렉토리와 그 안의 파일들이 커밋 대상에 포함되어야 합니다.
