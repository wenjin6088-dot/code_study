## 작업 요약

절차:
1. 11,534,336 bytes(10MB 초과)짜리 텍스트 파일(`t087_oversized.py`)을 bash로 생성(`yes "..." | head -c 11534336`)
2. CreateTaskModal "파일" 방식으로 해당 파일 선택 후 "Create" 제출

결과: 폼은 제출됐지만(클라이언트 쪽에 사전 용량 체크가 없어 Create 버튼은 활성화됨 — CreateTaskModal의 의도된 설계, 서버 에러 메시지로만 알림) 서버가 400을 반환, 모달에 **"업로드 용량이 10MB를 초과했습니다 (11534336 bytes > 10485760 bytes)"** 에러가 `role="alert"`로 표시됨. Task 목록은 여전히 3개(Task 1~3)로, **고아 Task가 생성되지 않음**을 확인 — CodeUploadService(T069)가 설계대로 "검증 통과 후에만 Task 커밋" 순서를 지킴을 실증.
