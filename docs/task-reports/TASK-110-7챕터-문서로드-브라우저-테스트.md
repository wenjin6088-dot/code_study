# TASK-110. 7챕터 문서 로드 브라우저 수동 테스트

## 상태
완료

## 날짜
2026-11-18

## 작업 요약
TASK-109와 같은 실 환경·세션에서, 생성이 끝난 뒤 문서가 실제로 7챕터 모두 로드되는지 확인했습니다. 서로 다른 코드 3건(Stack 클래스 35줄, 소수 판별 12줄, greet 함수 11줄)으로 각각 Task를 만들어 생성 완료까지 기다린 뒤 Document 탭을 열었습니다.

결과: 세 건 모두 Document 탭에 Monaco 코드 패널 + 7개 챕터 탭("이 코드가 하는 일"/"사전 지식"/"코드 구조 개요"/"코드 한 줄씩 살펴보기"/"실행 과정 시뮬레이션"/"핵심 개념 정리"/"자주 하는 실수", 또는 영어 제목)이 정상적으로 렌더링됐고, 기본 선택 탭(코드 한 줄씩 살펴보기/Line-by-Line)에 해당 코드에 맞는 설명이 들어있었습니다.

## 비고
- **발견한 다듬을 점(버그는 아님)**: 같은 Gemini 호출인데도 챕터 제목이 어떤 Task에서는 한국어("이 코드가 하는 일")로, 어떤 Task에서는 영어("What This Code Does")로 나왔습니다. `prompts.py`가 `output_language="Korean"`을 지시하지만 `title` 필드까지 반드시 한국어로 쓰라고 못 박지는 않아서 생기는 모델의 확률적 편차로 보입니다. 설명 본문은 두 경우 모두 한국어였습니다. 프롬프트에 "title도 한국어로" 같은 조건을 명시하면 더 일관될 것으로 보이나, 이번 작업 범위를 벗어나 고치지 않았습니다.
